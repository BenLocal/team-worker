# 交流与语言约定

> 默认简体中文交流与文档；代码中的注释、日志和错误信息一律使用英文。

- 交流语言：默认使用简体中文；仅在用户明确要求时使用英文。
- 代码注释：一律使用英文，包括 doc comment、行内注释、`// TODO`。按 Go 惯例，导出符号的 doc comment 以符号名开头（如 `// Receive consumes ...`）。
- 代码里的其他字符串：日志、错误信息、CLI 帮助文本（cobra 的 `Short` / `Long` / flag usage）都用英文，与现有代码一致。
- 标识符：保持英文，不用拼音。
- 文档：`README.md`、`AGENTS.md`、`docs/` 与 `skills/` 下的文档用简体中文，沿用现有风格。
- 提交信息与仓库既有风格保持一致。
